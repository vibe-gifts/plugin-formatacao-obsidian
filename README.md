# Formatador de Texto (plugin do Obsidian)

Você cola um texto no Obsidian e ele chega bagunçado. O Formatador arruma com um clique e ainda dá uma barra de formatação quando você seleciona um trecho.

## O que ele faz

- **Botão Formatar ao colar.** Depois de colar um texto, aparece um botão perto dele. Um clique e pronto.
- **Barra ao selecionar.** Selecione um trecho e a barra de formatação aparece em cima dele.
- **Comando para a nota inteira.** Na paleta de comandos, use "Formatar seleção (ou a nota inteira)".

## O que a limpeza arruma

- Marcadores diferentes viram lista normal.
- Títulos em caixa alta viram títulos.
- Linhas decorativas e espaços sobrando saem.
- Travessões viram vírgula, dois-pontos ou hífen, conforme a frase.
- Tabelas e blocos de código são arrumados à parte.

O plugin funciona só no seu computador. Ele não envia nada para a internet.

## Instalação

1. Baixe o projeto em **Code → Download ZIP** e descompacte.
2. Dentro do seu cofre, crie a pasta `.obsidian/plugins/formatador-de-texto`.
3. Copie para ela os arquivos `main.js`, `manifest.json` e `styles.css`.
4. No Obsidian, abra **Configurações → Plugins da comunidade**, atualize a lista e ligue o **Formatador de Texto**.

Nas configurações do plugin, dá para ligar ou desligar o botão e a barra separadamente.

Funciona no Obsidian para computador, versão 1.4.0 ou mais nova.
